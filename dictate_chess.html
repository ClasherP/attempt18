What is dictate chess

Dictate Chess is a Chrome extension that allows you to play games on chess.com using voice commands. It is aimed to be an accessibility tool and a tool to help with board vision/familiarity with chess notation. You can use this extension on: live games, bot games, analysis boards, puzzles

I regularly update this extension with requested features, so leave a review on the Chrome Web Store and I will look at your feedback

This is not a chess engine and does not provide any competitive advantage. It is intended to be used on long form time control games like rapid/classical.

Getting Started

To install the extension, download it from the Chrome Web Store at this link and pin the extension to the extension tab on Chrome:

Then to use the extension head to chess.com and press the top right icon highlighted in the picture.

It will then bring up the menu shown on the left, to turn on voice control click the microphone button and it should turn red and say "listening".

Everything you say should then be transcribed and shown into the gray box below the button, if not then head over to the troubleshooting section.

You can now speak commands into your microphone (e.g knight f6) and the extension will move the pieces on the board without having to interact with the board yourself!

To turn the microphone off, click the microphone button and it should turn black and say "off".

You will only be able to open this popup on chess.com games, puzzles, bot games, or analysis boards.

Voice Commands

Voice command are the verbal commands you speak to the extention, all voice commands should appear in the gray box below the microphone button (which is usefull so if you have any issues, you can see what the computer thinks you said).

There are 4 types of commands you could use with this extention:

  • Individual square commands
  • Double square commands
  • Piece-square commands
  • Special commands

Individual square commands

Individual square commands simply press on the stated square, for example, if you said "e5", the extension would click the e5 square.

This is useful if you're having issues with any of the other commands and need to click on one specific square to complete your move.

Double square commands

Double square commands are like individual square commands, but they involve saying two squares quickly, one after another. For example, if you said "e6 c4," the extension would click the e6 square, then quickly click the c4 square.

Piece-square commands

Piece square commands involve saying a piece followed by the square you want to move it to, this is similar to traditional chess notation. For example, saying "knight c6" or "queen g8" would move the piece to the desired square. The extension should calculate each piece's legal moves to determine which piece you intend to move (if there are multiple pieces of the same type on the board).

To differentiate the traditional pawn moves from the individual square commands (since you would usually just say the square), you'll have to say "pawn" followed by the square you want to move it to.

In the event that multiple pieces can go to the same square, you'll have to use a double square command to specify which piece you'd like to move. The extension will also highlight those pieces so you realise that you need to specify the piece.

You are able to premove if you speak fast enough, but it's not recommended.

Special commands

Currently, the only special commands are "long castle" and "short castle".

I am still working on implementing en paussant and pawn promotion, for the time being, if you'd like to complete these moves, please use the individual square commands.

Troubleshooting

If any of the below methods don't fix your problems, feel free to leave a Chrome Web Store review or email me at rjtuck.75@gmail.com with the subject as "dictate chess".

Voice commands are not getting picked up.

Firstly, to test if your microphone can be picked up by Chrome, go to this website to check your microphone.

If you can hear yourself clearly, then it's an issue with the extension, but if you can't hear yourself clearly, ensure you go to your Chrome settings and head over to the "site settings" tab.

There you'll be able to configure a microphone to use with Chrome. Additionally, make sure you select the "sites can ask to use your microphone" option.

Microphone too quiet

Unfortunately, i havn't had the chance to implement a microphone sensitivity slider, so for the time being you'll have to navigate to your control panel and turn your microphone sensitivity up manually.
